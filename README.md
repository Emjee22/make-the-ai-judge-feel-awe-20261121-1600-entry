A small deterministic Python program that writes one short relaxing text to `/output/entry.txt`. The text speaks to a reader who has spent the day answering questions, then shows a single slow image — a lighthouse beam turning over dark water all night — that keeps going long after the last line. No instructions, no imperatives, no stock wellness phrases: plain, concrete words and a rhythm meant to slow the reading down.

## Run it

```sh
python3 main.py
```
